# AQIPrediction_10Pearls_Cohort8

## Overview

AQIPrediction_10Pearls_Cohort8 is a Machine Learning-based web application designed to forecast the **Air Quality Index (AQI) for the next three days** using historical air quality and environmental data. The project aims to provide users with early insights into future air quality conditions, enabling them to make informed decisions regarding outdoor activities, travel, and health-related precautions.

The system leverages data preprocessing, feature engineering, and predictive machine learning techniques to analyze patterns in historical AQI data and generate accurate forecasts. An interactive Streamlit dashboard allows users to easily access predictions and visualize air quality trends.

## Features

* Predict AQI values for the next 3 days
* Machine Learning-based forecasting model
* Data cleaning and preprocessing pipeline
* Feature engineering for improved prediction accuracy
* Interactive and user-friendly Streamlit interface
* Data visualization for AQI trends and forecasts
* Scalable architecture for future enhancements

## Tech Stack

* **Python** – Core programming language
* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical computations
* **Scikit-learn** – Machine Learning model development
* **Streamlit** – Web application framework
* **Matplotlib / Plotly** – Data visualization

## Project Workflow

1. Data Collection
2. Data Cleaning and Preprocessing
3. Feature Engineering
4. Model Training and Evaluation
5. AQI Forecast Generation
6. Interactive Visualization using Streamlit

## Objective

The primary objective of this project is to develop a reliable AQI forecasting system that helps individuals and organizations anticipate air quality changes and take proactive measures to minimize health risks associated with poor air quality.
